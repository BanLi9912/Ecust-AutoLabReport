# 讲义 PDF → 分块 HTML

## 两个脚本

```
python pdf_blocks.py <pdf> <work> [first_page] [last_page]
    → <work>/blocks.json, <work>/figs/*.png, <work>/preview.txt

python build_sections.py <work>
    → <work>/html/<分块>.html, <work>/html/manifest.json
```

依赖：`python -m pip install pymupdf pillow`（本机已装 PyMuPDF 1.28.6）。

`first_page/last_page` 是 1-based 闭区间。一个讲义 PDF 常塞多个实验（磁化率那个是 1–4 页一个实验、5–10 页另一个），**先只解析本次那几页**，否则分块映射会串。

## pdf_blocks.py 干了什么

1. 用 `page.get_text('dict')` 把每页拆成 line，读 `bbox / spans[].size / text`。
2. 每行分类：
   - 正文：`cjk >= 5`，或 `cjk >= 2` 且（CJK 占比 > 0.45 或行尾是 `。；：？，`）；
   - 其余算公式行；`type==1` 的 image block 直接当插图。
3. 公式行按 **y 轴重叠**分带（`2pt` 容差），一条公式的所有行（分子分母、上下标）进同一带 → 整条裁一张图。
4. 段落合并：同页 + 下一行左对齐（`x0 <= 100`）+ 上一行右端顶到右边（`x1 > 400`）+ 行距 `< 1.9×字号` + 字号差 `< 0.6`。
5. 裁图：`clip = bbox ± 2~3pt`，`dpi=300`，文件名 `f<页>_<y>_<序号>.png`。
6. 碎带过滤：宽 ≤ 45pt 或有效字符 ≤ 2 的公式带丢掉（孤立符号、页码残留）。

### 调参位置（都在 pdf_blocks.py 里）

| 症状 | 改哪 |
| --- | --- |
| 公式被切成半截 / 拆成多张 | 分带的 y 容差（`- 2` / `+ 2`） |
| 一个字被当公式裁出来 | 碎带过滤的 `> 45` 和 `> 2` |
| 段落太碎（一句一段） | 段落合并的行距系数 `1.9`、`x1 > 400` |
| 正文行被误判成公式 | `is_prose_line` 的 CJK 阈值 |
| 图糊 | `dpi=300` 调高 |

### 反面教材（别走回头路）

- 按 **span** 逐块聚簇：磁化率讲义 4 页炸出 **226 张碎图**（`fig_1_630_15.png 36x59`），还把正文里的「1.」前缀当公式吞掉。→ 必须行级 + y 分带。
- 从公式抽文字：`χM=(ΔW… )·2ghM/(WH0²)` 这类下标、根号、希腊字母全丢，抽出来没法用。→ 一律裁图。

## build_sections.py

- `HEAD_MAP`：精确匹配讲义标题（一、实验目的 → 实验目的 … 七、进一步讨论 → 不入库）。
- `resolve_heading()`：匹配不上就按关键字认（目的/原理/试剂/仪器/步骤/操作/数据/结果/思考/讨论）；含「进一步/参考/附录」的标题丢掉。
- 图片：PIL 缩到宽 ≤900px，PNG 优化，base64 内嵌；宽 <240px 的不加 width 样式（避免小图被拉大）。
- 输出顺序固定按网站的 `SEC_ORDER` 八块走，生成空文件的块留给后面手写。

## 分块 HTML 的写法约定

```html
<p>1、掌握古埃(Gouy)法测定磁化率的原理和方法。<br />
2、测定三种络合物的磁化率，求算未成对电子数，判断其配键类型。<br />
3、熟悉特斯拉计的使用。</p>

<p>样品管的磁化率χ<sub>空管</sub>与磁场强度H的关系为…</p>

<p><img src="data:image/png;base64,iVBORw0KGgo…" style="width:600px" /></p>
```

- 化学式用 `<sub>`（`K<sub>4</sub>Fe(CN)<sub>6</sub>`），指数用 `<sup>`（`10<sup>-9</sup>`），希腊字母直接写 Unicode（χ、μ、Δ、α）。
- 一段一个 `<p>`，段内换行用 `<br />`；**不要**用 `\n` 当换行（CKEditor 会直接吃成空格）。
- 图片单独一个 `<p>`，紧跟在它解释的那段文字后面——位置由这一步定死，之后不再调。
- 表格：`<table>` 在 CKEditor 里能正常显示，但本流程一般用 `<p>`+`<br />` 列数据就够。

## 各块内容从哪来

| 分块 | 来源 | 处理 |
| --- | --- | --- |
| 实验目的 | 讲义 | 照抄 |
| 实验原理 | 讲义 | 照抄正文 + 公式图 + 装置图/结构图，按讲义顺序排 |
| 仪器和试剂 | 讲义 | 合并成两行，试剂补 A.R. 之类级别标注 |
| 实验步骤 | 讲义 | 照抄，编号层级压平（1. / (1)） |
| 原始数据记录 | **纸面** | 只做录入与排版，不改数 |
| 数据处理及实验结果 | 纸面 + 计算 | 公式、代入过程、结果表、相对误差 |
| 分析与讨论 | 自己的推导/误差分析 | 模型可写，但要告诉用户这是模型写的 |
| 思考题 | 讲义题目 + 答案 | 答案模型可写，明确标注 |

纸面数据拿不到就留空并告诉用户——**不要编数据**，这是实验报告，编数字等于造假。

## 自检清单

- [ ] `preview.txt` 里每段都是通顺的句子（不是一句一断）

## 古埃法（Gouy）磁化率：数据处理怎么写

讲义给了四条式子：49-13 `F = ½χAH²`、49-14 `χM = 2ghM(ΔW − ΔW₀)/(W H² μ₀)`、49-15 `χm(莫尔氏盐) = 9500/(T+1) × 4π×10⁻⁹`、49-8/49-9（μm 与 n）。

**单位坑（最容易翻车）**：讲义的 H 是 **奥斯特（Oe，CGS）**，而特斯拉计读的是 **T**，1 T = 10⁴ Oe。直接把 0.35 T 当 H 代进公式，结果会差好几个数量级。

**稳妥算法（比值法，h、A、H 全消）**：

```
χm(莫尔氏盐) = 9500/(T+1) × 4π×10⁻⁹        T 用热力学温度（平均温度 ℃ + 273.15）
χM(样品) = χm(莫尔氏盐) × M × [(Δm_s − Δm_0)/(Δm_M − Δm_0)] × (W_M/W_s)
μm = sqrt(3kT·χM/(NA·μ0))
n:  n(n+2) = (μm/μB)²
```

前提：同一支样品管、装填高度相同；`Δm_0` 是空管加场前后的称量差（通常为负，玻璃/空气反磁性），**必须减掉**。

实测样例（「分子磁化率测定」reactions/<rxn_id>）：平均温度 23.1 ℃ → T = 296.25 K；χm(莫尔氏盐) = 4.016×10⁻⁷ m³·kg⁻¹；三组 χM = 1.371/1.370/1.320 ×10⁻⁷，χ̄M = 1.354×10⁻⁷ m³·mol⁻¹；μm = 4.69×10⁻²³ J·T⁻¹（5.05 μB）；n = 4.15 ≈ 4 → Fe²⁺ 高自旋 d⁶，电价配键。

**常见错误**（批改/自查时看这几条）：

- 把摄氏温度直接代进 `9500/(T+1)` → χ 偏大 10% 以上；
- 忘了减 `Δm_0`；
- 称量均值算错（纸上记录值与自己算的均值不一致时，以表内三次读数的均值为准，并在报告里说明）；
- 误差分析只写"仪器误差"：按 49-14，相对误差 = δ(Δm)/Δm + δW/W + **2δH/H** + δh/h，磁场强度是平方项、通常是最大来源。
